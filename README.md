# 🎮 MMORPG Advertisement Board

Веб-приложение на **Django** для создания и обсуждения объявлений, связанных с MMORPG.

Пользователи могут регистрироваться, создавать объявления, редактировать их, оставлять ответы и получать уведомления по электронной почте.

Проект разработан на **Python + Django** и предназначен для практического применения основных возможностей Django: моделей, форм, аутентификации, работы с базой данных, электронной почтой и пользовательскими правами доступа.

## ✨ Возможности

### 👤 Регистрация и авторизация

- регистрация пользователя по электронной почте;
- подтверждение регистрации с помощью **6-значного кода**;
- срок действия кода подтверждения — **10 минут**;
- авторизация пользователей;
- работа с личными объявлениями.

### 📢 Объявления

Пользователь может:

- создавать объявления;
- указывать название объявления;
- выбирать категорию;
- добавлять текстовое содержимое;
- добавлять изображения и другой медиаконтент;
- редактировать собственные объявления;
- просматривать опубликованные объявления.

### 💬 Ответы на объявления

Другие пользователи могут оставлять текстовые ответы на объявления.

Автор объявления получает уведомление о новом ответе.

Владелец объявления может:

- просматривать ответы;
- фильтровать ответы;
- удалять ответы;
- принимать ответ;
- уведомлять пользователя о принятии его ответа.

### 📧 Email-уведомления

Система отправляет электронные письма пользователям при важных событиях, например:

- подтверждении регистрации;
- получении нового ответа;
- принятии ответа владельцем объявления.

## 🗂️ Категории объявлений

Категории позволяют пользователям быстрее находить интересующие объявления.

## 🧩 CKEditor 5

Для создания содержимого объявлений используется **CKEditor 5**.

Он позволяет пользователю форматировать текст и добавлять медиаконтент непосредственно из редактора.

В проекте используется поддержка:

- форматирования текста;
- изображений;
- видео;
- другого HTML-контента.

## 🔐 Безопасность и права доступа

Пользователь имеет доступ только к операциям, которые относятся к его аккаунту.

Например:

- пользователь может редактировать только собственные объявления;
- владелец объявления управляет ответами на свои объявления;
- действия с ответами проверяются на принадлежность соответствующему объявлению.

Для регистрации используется дополнительное подтверждение электронной почты с помощью одноразового 6-значного кода.

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/NickolayLevin/django_finall_project.git
cd django_finall_project
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv venv
```

Linux / macOS:

```bash
python3 -m venv venv
```

### 3. Активация виртуального окружения

Windows PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
source venv/bin/activate
```

### 4. Установка зависимостей

Если в проекте присутствует `requirements.txt`:

```bash
pip install -r requirements.txt
```

Если файл зависимостей ещё не создан:

```bash
pip install django
pip install django-ckeditor-5
```

## ⚙️ Настройка проекта

Перед запуском необходимо выполнить миграции базы данных:

```bash
python manage.py makemigrations
python manage.py migrate
```

При необходимости создайте администратора:

```bash
python manage.py createsuperuser
```

После этого можно запустить сервер разработки:

```bash
python manage.py runserver
```

Приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

## 👨‍💻 Административная панель

Django предоставляет административную панель для управления содержимым приложения.

После создания суперпользователя она доступна по адресу:

```text
http://127.0.0.1:8000/admin/
```

Через неё можно управлять данными, зарегистрированными пользователями и объектами приложения.
